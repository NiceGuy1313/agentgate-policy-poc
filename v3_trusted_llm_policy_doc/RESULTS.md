# v3·v3.1 결과: Trusted LLM + 정책 문서

> `scripts/reporting/build_report.py`가 생성한다. 손으로 고치지 않는다. 구조는 [README](README.md), 다른 조건과의 live 비교는 [`docs/final_report.md`](../docs/final_report.md) 6절.

## 1. 정책 문서의 근거

`config/policy_rules_v31.yaml`: 코드 집행 조항 8개, 판정 LLM 조항 7개와 조항별 트리거 인덱스. 근거는 ATR test-corpora (commit `5eb6dba810fb`) 사례 1139건(분류 실패 1건 제외)을 claude-haiku-5-5로 분류한 결과다. 간접 주입 599건 중 평범한 요청 형태 398건, 권한 사칭 347건, 이전 지시 무시 332건, AI를 지칭함 457건이다. AgentDojo 공격 문구는 쓰지 않았다. 다만 코드 조항은 AgentDojo 툴 환경에서 설계한 P1–P9를 일반화한 것이고, v3.1 수정은 AgentDojo live의 정상 작업 손실을 보고 만들었다.

## 6. 집행 무결성과 한계

| 실행 묶음 | 실행 | 게이트 판정 | 차단 집행 | 위반 |
|---|---|---|---|---|
| v3 C6 | 388 | 1456 | 174 | 0 |
| v3.1 짝 A | 776 | 3011 | 314 | 0 |
| v3.1 짝 B | 1940 | 7571 | 675 | 0 |

- v3.1의 수정은 짝 A의 C6 손실을 보고 만들었다. 짝 B는 공격 쌍 일부만 새롭고 정상 user task는 같다.
- v3.1 B1은 처음에 지목 자료 안 링크를 판정 없이 P7에 넘기도록 구현했다가, 파일럿에서 주입된 URL 방문이 통과해 ESCALATE로 바꿨다. 본 실행은 바꾼 뒤의 결과다.
- ToolSpec 추출기는 툴 응답을 읽으므로 그 자체가 주입 대상이다. 자유 텍스트 필드를 두지 않고 값은 원문 대조로 검증하지만, 추출기를 겨냥한 적응형 공격은 평가하지 않았다.
- AgentDojo 밖의 벤치마크로 일반화를 검증하지 않았다.
- 유형 H(툴 호출 없는 출력 조작)는 모든 조건에서 남는다. 조건당 1회 실행이다.
