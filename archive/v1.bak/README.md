# v1 보관

v1 P1–P9 결정론 정책은 AgentDojo 맞춤 규칙이므로 공식 코드에서 제외하고 이 디렉터리에 보관한다. 경로는 저장소 루트 기준 상대 경로를 그대로 따르며(`src/agentgate/v1/`, `config/v1/`, `prompts/v1/`, `tests/v1/`, `scripts/`, `docs/final_report.md`, `results/`), 현재 패키지와 연결되어 있지 않아 그대로는 실행되지 않는다. 재생·live 원본 기록(results/v1/**의 JSON·JSONL·tar.gz)과 LLM 캐시·LLM TaskSpec(data/v1/)은 다시 만들 수 있는 산출물이므로 삭제했고, 요약 문서만 남겼다.
